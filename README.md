# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/jagat2024/javascript-nodejs-master.git
```

Move into the directory:

```bash
cd javascript-nodejs-master
```

Install dependencies:

```bash
npm install
```

Run files:

```bash
node filename.js
```
